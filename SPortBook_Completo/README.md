# SPortBook — Protótipo completo

Sistema de reservas de quadras para apresentação.

## Funcionalidades
- Login separado de usuário e administrador.
- Cadastro de usuários pelo administrador.
- Cadastro/ativação de quadras.
- Consulta de horários.
- Reserva de quadra.
- Bloqueio de horários pelo administrador.
- Cancelamento de reservas.
- Validação de conflito de horários.
- Limite de 2 horas por reserva.
- Uma reserva por usuário por dia.
- Persistência local com `localStorage`.
- Interface responsiva em verde e branco.

Extraia o ZIP e abra `index.html` no navegador.

Observação: esta versão é um protótipo para apresentação. Os dados ficam no navegador usando localStorage; não há banco de dados nem autenticação real de servidor.
